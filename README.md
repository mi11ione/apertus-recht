# Apertus-Recht

Hack Apertus 2026, Track 1B (Swiss Voices · behavioural alignment). The submission lives in [`track_1b/`](track_1b/):
a DE/FR/IT minimal-twin evaluation set for Art. 261bis StGB with code-computed gold, a self-checking harness and the
reusable `statute-twins` package. Run it with `make run` (from here or from `track_1b/`).
